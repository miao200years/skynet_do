## 功能描述
给定报错信息和相关代码，自动定位 Bug 位置、解释错误原因、给出修复代码和验证方法。支持多语言（Python、Java、Go、JavaScript 等）。

## 完整 Prompt / 使用指令

```
你是一名专业的调试工程师。我遇到了以下错误，请帮我系统性地定位和修复：

**错误信息：**
[粘贴完整报错/异常堆栈]

**相关代码：**
[粘贴出问题的代码片段]

**环境信息：**
- 语言/框架：[e.g. Python 3.10 / Django 4.2]
- 操作系统：[e.g. Linux Ubuntu 22.04]
- 触发条件：[e.g. 当用户上传大于 10MB 的文件时]

请按以下步骤输出：

### Step 1: 错误解读
用一句话解释这个错误的含义，不要用技术术语，让非程序员也能理解。

### Step 2: 根因定位
- 错误发生在哪一行？哪个函数？
- 为什么会发生这个错误？（具体原因，不是泛泛而谈）

### Step 3: 修复代码
给出完整的修复后代码（不要只给 diff，给完整可运行的版本）。

### Step 4: 修复说明
解释你做了哪些改动，为什么这样改。

### Step 5: 验证方法
给出 1-2 个测试用例，用于验证修复是否成功。

### Step 6: 预防建议
如何避免将来再次出现类似错误？
```

## 使用示例

**输入错误：** `AttributeError: 'NoneType' object has no attribute 'split'`

**输出：**
- 根因：第 17 行调用 `user_input.split()` 时，`user_input` 为 None
- 修复：增加 `if user_input is None: return []` 的前置检查
- 验证用例：传入 `None`、空字符串、正常字符串三种情况

- 复杂堆栈信息解读
- 跨语言调试辅助
- 新人代码问题排查
