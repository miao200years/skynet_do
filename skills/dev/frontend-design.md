# frontend-design

> Create distinctive, production-grade frontend interfaces with high design quality.

## 触发场景

用于构建 Web 组件、页面、应用、海报时使用。能生成有创意的、有设计感的 UI 代码，**刻意避免千篇一律的 AI 审美**（紫色渐变 + Inter 字体套路）。

## 核心指令内容

```
This skill guides creation of distinctive, production-grade frontend interfaces
that avoid generic "AI slop" aesthetics.

Before coding, commit to a BOLD aesthetic direction:
- Purpose: What problem does this interface solve? Who uses it?
- Tone: Pick an extreme — brutally minimal / maximalist chaos /
  retro-futuristic / organic / luxury / brutalist / art deco / editorial, etc.
- Differentiation: What makes this UNFORGETTABLE?

CRITICAL: Choose a clear conceptual direction and execute it with precision.
Bold maximalism and refined minimalism both work — the key is intentionality.

Then implement working code (HTML/CSS/JS, React, Vue, etc.) that is:
- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point-of-view
- Meticulously refined in every detail
```

## 设计哲学原则

| 维度 | 要求 |
|------|------|
| **排版** | 使用非常规字体组合；避免 Inter everywhere |
| **色彩** | 限制色板（2-3色）或大胆撞色，不用默认蓝/紫 |
| **空白** | 刻意的空间节奏，而非填满每个角落 |
| **动效** | 有意图的过渡，不是为了动而动 |
| **布局** | 破格网格；不总是居中的英雄区块 |

## 使用示例

```
"帮我做一个 SaaS 落地页，要工业风，不要那种科技蓝渐变"
"用 brutalist 风格给我写一个个人简介组件"
"做一个 Art Deco 风格的数据仪表板 HTML"
```

## 输出物

- 直接可运行的 HTML/CSS/JS 或 React 组件
- 包含完整样式，不依赖外部 UI 库
