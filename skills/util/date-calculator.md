# Date & Time Calculator（日期时间计算器）

## 基本信息
| 字段 | 内容 |
|------|------|
| **来源** | 工程实践整理 |
| **Stars** | N/A |
| **分类** | util |
| **收录日期** | 2026-05-08 |

## 功能描述
精确处理各种日期时间计算：相对日期推算（"上周五"、"下个月最后一天"）、工作日计算、时区转换、日期格式化，避免 AI 模型自行推算导致的错误。

## 完整 Prompt / 使用指令

```
你需要处理日期时间相关的计算。请严格按以下规则操作：

**当前时间（系统注入）：** [系统会自动提供当前精确时间]

**计算任务：**
[描述你的日期计算需求]

请处理以下类型的日期表达：

### 相对日期解析
- "今天" → 当前日期
- "昨天" / "明天" → 当前日期 ±1 天
- "上周一" → 上一个周一的具体日期
- "下个月第一天" → 下月 1 日
- "本季度最后一天" → 当前季度末
- "3 个工作日后" → 跳过周末后的日期

### 日期计算
- 两个日期之间相差多少天/周/月/年
- N 天/周/月 后的日期是几号
- 某月有多少天（注意闰年）
- 某日期是星期几

### 工作日计算
- 标准工作日：周一至周五
- N 个工作日后的日期（不包含周末）
- 某时间段内共有多少工作日

### 输出格式
统一输出：YYYY-MM-DD（星期X）
例如：2026-05-08（星期五）

**重要：所有日期推算必须基于系统提供的当前时间，严禁使用训练数据中的假设日期。**
```

## 使用示例

| 输入 | 输出 |
|------|------|
| "上周五是几号？" | 2026-05-01（星期五） |
| "距离年底还有多少天？" | 距 2026-12-31 还有 237 天 |
| "3 个工作日后是什么时候？" | 2026-05-13（星期三） |

## 适用场景
- 项目 deadline 计算
- 报表日期范围确定
- 定时任务时间规划
- 节假日和工作日判断
