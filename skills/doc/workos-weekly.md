## 功能描述
根据本周工作记录（commit 记录、卡片完成情况、会议纪要等），自动生成结构清晰的周报，按项目/模块分组，突出重点进展、风险和下周计划。

## 完整 Prompt / 使用指令

```
你是一名善于总结提炼的工作助手。请根据以下信息，生成一份本周工作周报。

**本周工作记录：**
[粘贴以下任意组合的内容：
- Git commit 记录（git log --oneline --since="1 week ago"）
- 已完成的任务卡片列表
- 会议纪要摘要
- 自己的工作日志/笔记]

**周报格式要求：**
- 读者：[直属leader / 部门 / 全组]
- 风格：[简洁bullet风格 / 详细叙述风格]
- 是否包含下周计划：[是/否]

请按以下模板生成周报：

---
# 本周工作总结（YYYY.MM.DD - YYYY.MM.DD）

## 一、本周完成工作
### [项目/模块名称A]
- ✅ [完成事项1]（简要说明进展和结果）
- ✅ [完成事项2]

### [项目/模块名称B]
- ✅ [完成事项]

## 二、进行中工作
- 🔄 [进行中事项]（当前进度：X%，预计完成时间：XX）

## 三、风险与阻塞
- ⚠️ [风险描述]：[影响范围] | 解决方案：[方案]
  （无风险则写：本周无明显风险）

## 四、下周计划
- [ ] [计划事项1]（负责人：XXX，预计完成：周X）
- [ ] [计划事项2]

## 五、需要支持
（如有需要他人协助的事项，在此列出；否则省略本节）
---
```

## 使用示例
输入 git log 和 iCafe 已完成卡片列表，输出结构化周报，自动按模块分组，提炼关键进展。

## 适用场景
- 每周五快速生成工作周报
- 汇总多个项目进展
- 向上汇报工作成果
